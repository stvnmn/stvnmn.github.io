# stvnmn.com

Personal portfolio and project page, built as a lightweight static site.

## Featured project

### Budget Tracker

A self-hosted weekly budget tracker with a spending dashboard, category breakdown, and transaction history. It supports configurable budgets, categories, currency, and timezone, and stores data in a local SQLite database. The app runs in Docker and is built with Flask.

- [View the Budget Tracker repository](https://github.com/stvnmn/budget-tracker)
